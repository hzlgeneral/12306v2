# 火车票发票合并工具（桌面版 · 支持 Windows 与 macOS）

把原 Docker 网页程序的核心功能做成一个 **双击即可运行的单文件小程序**，
无需安装 Docker，无需起 Web 服务。功能与原版一致：

1. 从邮箱拉取 12306 电子客票 PDF 发票（按日期范围筛选）
2. 自动识别每张发票的**火车开车时间**
3. 按开车时间**从早到晚**排序后合并为一页/多页 PDF
4. 也可跳过邮箱，直接选一个本地文件夹里的 PDF 合并

## 重要：运行不需要 Python

打包出的 `.exe`（Windows）/ `.app`（macOS）**运行时完全不依赖 Python**——
所有依赖（Python 解释器、pymupdf、pillow、邮箱/PDF 逻辑）都已被打进单文件。
只有「打包这一步」需要 Python 环境（见下方方式二 / 三）。
**普通使用者拿到 exe/app 后，自己机器上不需要安装任何东西。**

> 邮箱与授权码**不会写死在程序里**：`config.py` 中的邮箱/密码已清空，
> 用户每次在程序界面自行填写自己的邮箱和授权码（IMAP 授权码，非登录密码）。
> **IMAP / SMTP 服务器与端口会根据邮箱域名自动匹配，无需手填**（点「授权码(如何获取?)」可跳转对应服务商的申请教程）。

## 目录结构

```
windows_app/
├── main.py            # 图形界面程序（tkinter）
├── requirements.txt   # 依赖
├── build.bat          # 一键打包成 Windows .exe
└── README.md
├── ../.github/workflows/build-windows.yml   # 云端自动打包 Windows .exe
├── ../mac_app/build.sh                      # 一键打包 macOS .app
```
> `main.py` 复用项目根目录的 `ticket_core.py`（取时间/排序/拼版）、
> `email_handler.py`（拉取邮件）、`config.py`（仅存默认 IMAP 服务器），
> 与 Docker 网页版共用同一份已修复的排序逻辑，不会出现两份代码分叉。

## 方式一：直接运行（开发/调试，需本机有 Python）

```bat
pip install -r requirements.txt
python main.py
```

## 方式二：自己打包成独立 .exe（需本机装一次 Python）

```bat
双击 build.bat
```

双击即可用，对方无需安装 Python。**

## 使用步骤

1. 打开程序，填写邮箱配置（首次为空，需自己填）：
   - **邮箱地址**：填入后程序会**自动匹配** IMAP/SMTP 服务器与端口（QQ/163/126/139/gmail/outlook 等常见服务商已内置；未知域名按 `imap.<域名>` / `smtp.<域名>` 猜测）。界面下方会显示「已自动匹配 …」，无需手动输入服务器。
   - **授权码**：点标签「授权码(如何获取?)」可**直接打开对应服务商的申请教程**（QQ 邮箱：设置 → 账户 → 开启 IMAP/SMTP → 生成授权码）。注意**授权码不是登录密码**。
   - **收件人邮箱**：把合并后的 PDF 发到这个邮箱（可选；保存后下次自动填入）。
   - 可选勾选「合并后自动发信」：合并完成顺便自动发出。
2. 填写「日期从 / 日期到」（格式 `YYYY-MM-DD`，不填则取近 30 天）
3. 点 **合并下载（拉取+合并）** —— 一步全自动：拉取发票 → 按开车时间排序 → 合并成单份 PDF（勾选发信则顺带发出）
4. 若已有 PDF：点 **合并「发票」文件夹** 或 **选本地PDF文件夹合并**
5. 点 **发送到邮箱** —— 把当前合并好的 PDF 通过 SMTP 发到「收件人邮箱」（需已填邮箱地址、授权码、收件人且存在合并 PDF）。发送成功后设置会**永久保存**。
6. 点 **打开输出PDF** 查看结果。输出路径：Windows 为程序同目录 `output\火车票发票排列结果.pdf`；**macOS 为 `~/Documents/火车票发票合并/output/火车票发票排列结果.pdf`**（合并下载的发票也存于此目录）。

## 设置保存（永久保存）

- 第一次「合并下载」成功后，程序会弹窗问：**是否保存邮箱与服务器设置，下次自动填入？**
  选「是」→ 写入程序同目录的 `mail_settings.json`（含邮箱、授权码、收件人、自动匹配的服务器）。
- 点 **发送到邮箱** 成功后，设置会**自动永久保存**（含收件人），下次打开自动回填。
- 已保存后标题栏显示「✔ 已载入上次保存」，不再弹窗询问。
- 想清除保存：删掉 `mail_settings.json` 即可（该文件已在 `.gitignore` 中，不会被提交/分享）。
- ⚠️ 安全提示：该文件含你的授权码，**不要连 exe 一起发给别人**；发给别人请用「未保存」状态。

## 排序修复说明（与原 Docker 版同源修复）

原程序部分发票排序错乱的根因：12306 电子客票里「出发日期」与「HH:MM开」
两行之间常夹有一行文字（如「电子发票（铁路电子客票）」），旧正则要求二者紧邻，
导致开车时间提取失败变 `None`、被排到末尾。本程序使用的 `ticket_core.py`
已让日期与时间之间允许夹任意文字，排序恢复正常。

## 备注

- 邮箱授权码仅在本地用于登录 IMAP 拉取发票，不会上传，也不会写死在程序里。
- 每次「拉取邮件」会先清空本地 `发票` 文件夹再写入，避免重复。
## macOS 版

- 本仓库已直接生成可用的 `dist/火车票发票合并.app`（带图标，双击即用，无需安装 Python）。
- 重新打包（例如换了图标 / 改了代码）：`bash mac_app/build.sh` —— 自动建 venv、装依赖、产出 `dist/火车票发票合并.app`。
- **数据目录**：macOS 打包版的工作目录在 `~/Documents/火车票发票合并/`（含 `发票/` 与 `output/`），不在 app 包内，便于查看与管理；Windows 版则在 exe 同级目录。
- **未签名处理**：Mac 首次打开未签名应用会被拦截，二选一：
  - 右键点击 `火车票发票合并.app` →「打开」→ 弹窗里再点「打开」；
  - 或终端执行：`xattr -dr com.apple.quarantine dist/火车票发票合并.app`。
- 从邮箱拉取的发票、合并结果、保存的邮箱设置都在这个数据目录，重装 app 不会丢。
